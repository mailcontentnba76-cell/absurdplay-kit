1. Hình chuyển động thật → pipeline ảnh tĩnh hiện tại không đạt. Phương án đề xuất: Blender dựng nhân vật khối + hoạt hình (0 credit) — cần làm thử.

3. Phụ đề: kiểu mới (1–3 từ, giữa khung, từ khóa vàng).
4. Nhân vật & trường học: thiết kế gốc, không sao chép nhân vật/tai nghe tai mèo/tên game của mẫu. Tên game có thương hiệu (Fortnite) → dùng game hư cấu.
